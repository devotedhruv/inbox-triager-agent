# Personal Triage Rules Doc

## Buckets
1. **Needs reply today**: Urgent, time-sensitive, VIP personal asks, meetings today, or routine scheduling.
2. **Needs reply this week**: Important inquiries with flexible timelines, non-urgent partner intros.
3. **FYI / no action**: Status updates, receipts, completed ticket notifications, read-only announcements.
4. **Noise**: Newsletters, automated marketing, cold outreach, promotional notifications.

## Rules & Overrides
- **VIP Rule**: Senders in `vip_list.txt` are NEVER classified as Noise unless the message is an automated bulk newsletter (e.g., contains unsubscribe link / no-reply).
- **Calendar Rule**: If an email requests a meeting or refers to an event, check `calendar.json`. If the requested slot is free, draft a confirmation.
- **Drafting Boundaries**:
  - Draft routine replies (confirming a free meeting slot, quick acknowledgment).
  - Voice: Casual, direct, no corporate fluff ("Sounds good, 2pm Thursday works for me. See you then! - Dhruv").
  - NEVER draft if: commits to a date, price, contract term, or decision; or if from unknown sender / potential phishing.
